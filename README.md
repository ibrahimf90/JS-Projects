# Ibrahim's Projects Sandbox

A dedicated space where I experiment, build, and showcase small web projects using HTML, CSS, JavaScript, and modern design principles.

## 🚀 Overview

This portfolio contains a collection of interactive web applications and tools demonstrating various programming concepts, UI/UX patterns, and modern web development techniques. Each project is self-contained and focuses on specific functionality while maintaining a consistent, polished design aesthetic.

## 🎨 Design Philosophy

- **Modern UI**: Glassmorphism effects, smooth animations, and contemporary design patterns
- **Responsive**: All projects are fully responsive and work across desktop, tablet, and mobile devices
- **Consistent Styling**: Unified design language with CSS variables and reusable components
- **User Experience**: Intuitive interfaces with clear feedback and smooth interactions

## 📁 Project Categories

### 🔧 Utilities & Tools

- **Bank Account Manager** - Track bank accounts with deposit, withdrawal, and balance management
- **Calories Counter** - Monitor daily calorie intake with meal tracking and summaries
- **Voting System** - Create and vote on polls with real-time counting
- **To-Do List** - Organize tasks with a clean, modern interface
- **Todo App** - Advanced task management with local storage persistence

### 🎮 Games & Fun

- **Drum Machine** - Create beats and rhythms with an interactive drum machine
- **Media Playlist** - Beautiful music player with playlist management
- **Quiz Game** - Test your knowledge with an engaging quiz
- **Games Collection** - A collection of fun mini-games
- **Switch Colors** - Generate random colors and color schemes

### 📝 Forms & Validation

- **Form Validation** - Advanced form validation with real-time feedback and regex patterns
- **Email Secret** - Hide email addresses and secrets with encode/decode functionality

### 🖱️ Interactive Components

- **Tab List** - Interactive tabbed interface with smooth transitions

### ☁️ Applications

- **Weather App** - Real-time weather information for any location
- **Bookmark Manager** - Save and organize favorite web links by categories
- **Shopping Cart** - Interactive dessert shopping cart with real-time calculations
- **Recipe Ingredient Converter** - Convert recipe ingredients between different units
- **Brazil Football Squad** - Explore Brazil's star players for World Cup 2026

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern HTML features
- **CSS3**: 
  - CSS Variables for theming
  - Flexbox and Grid layouts
  - Glassmorphism effects
  - CSS animations and transitions
  - Responsive design with media queries
- **JavaScript (ES6+)**:
  - Fetch API for data retrieval
  - Async/await for asynchronous operations
  - DOM manipulation
  - Event handling
  - Local Storage for data persistence
  - Regular expressions for validation
- **External Libraries**:
  - Font Awesome (icons)
  - Google Fonts (Inter, Playfair Display, Syne, DM Mono)
